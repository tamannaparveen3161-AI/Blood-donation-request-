#  Blood Donation Request Website

This is a simple and user-friendly Blood Donation Request website built using HTML, CSS, and JavaScript.

##  Project Description
The purpose of this project is to help people request blood donations easily by filling out a form. The website collects basic details like name, blood group, contact number, and location so that donors can respond quickly.

##  Technologies Used
- HTML5
- CSS3
- JavaScript

##  Features
- Simple and clean user interface
- Blood donation request form
- Input validation using JavaScript
- Responsive design (basic)
